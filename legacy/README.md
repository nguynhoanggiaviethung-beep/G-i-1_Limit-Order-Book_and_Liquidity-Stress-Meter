# Archived project material

This folder preserves earlier project work for historical reference. The active project is the Limit Order Book & Liquidity Stress Meter in the repository root.

- `tail_risk_backend/` contains the previous volatility, VaR/ES, forecast, collector, research configuration, scripts, and their tests.
- `results_tail_risk/` contains generated outputs from that earlier scope.
- `prior_binance_lob_volatility/` and `tail_risk_presentation/` are older archived deliverables.

Archived code is intentionally outside the active Python package and CI test path. The active tests remain under `backend/tests/`.
